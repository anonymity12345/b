# Ex-Omni-2D Supplementary Materials

This archive accompanies the anonymous review submission. It contains:

| Location | Contents |
| --- | --- |
| `Code/` | Model implementation, inference pipeline, example configurations, supporting scripts, and environment specifications. |
| `Constructed_Training_Data/vtp_annotations.jsonl` | 123,787 generated Stage 3/4 Visual Thought Plan (VTP) annotation records. Each record contains the sample ID, structured prompt, media references, speech-token reference, frame rate, and sample rate. |
| `Output_Examples/full_sequence/` | Ten generated full-sequence video examples with audio, numbered `1.mp4` through `10.mp4`. |
| `Output_Examples/streaming/` | Ten generated streaming video examples with audio, numbered `1.mp4` through `10.mp4`. |
| `Interactive_Demo.mp4` | Recorded demonstration of the end-to-end interactive system. |
